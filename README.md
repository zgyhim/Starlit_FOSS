# 星伴 Starlit

一个只属于你的本地 AI 伙伴。

星伴是一个纯本地运行的桌面应用。你可以和 10 位来自蔚蓝档案世界的角色一对一聊天，她会记住你说过的话，会在安静的时候主动找你，也会用自己的方式关心你。

不需要账号，不需要云端同步，聊天记录和记忆都只保存在你的电脑上。

> 本项目是「星伴」的 Tauri 2 重写版本。

---

## 她是什么样的伙伴

- **一对一私聊**：文字、表情包、引用、撤回、转发，像平时用聊天软件一样
- **有自己的人设**：每个角色都有独立的说话方式、性格和边界，不是套同一个模板
- **会记住你**：重要的偏好、约定和发生过的事会被记下来，在之后的聊天里自然提起
- **会主动找你**：上线问候、想起你、分享心情、偶尔回顾你们聊过的事
- **有自己的节奏**：不会秒回轰炸，也不会在你忙的时候打扰；深夜会安静下来
- **本地面貌**：原版角色头像、表情包合集、聊天气泡和背景都可以按角色设置

- 语音合成 / 朗读（TTS）

这两项已列入不做清单，界面入口也已移除。

## 开始使用

### 直接运行

从 Releases 下载对应平台的安装包，安装后打开即可。

首次启动会准备角色、人格和表情资源，需要多等一会儿；加载页会显示进度。

### 配置模型

星伴需要一个大模型服务来生成回复，支持任何 OpenAI 兼容接口：

1. 打开「设置 → 高级与开发者配置」
2. 填写接口地址、模型名和 API Key
3. 保存后即可开始聊天

默认配置面向 DeepSeek：

```yaml
base_url: https://api.deepseek.com
model: deepseek-chat
reasoning_effort: low
```

API Key 只保存在本机的配置文件里，不会上传，也不会写进日志。

### 从源码运行

```bash
npm install
npm run dev
```

Linux 需要 `webkit2gtk-4.1`、`gtk+-3.0`、`libsoup-3.0`；Windows 需要 WebView2。

## 你的数据在哪

所有内容都在本机的用户数据目录：

- Linux：`~/.local/share/starlit-desktop`
- Windows：`%APPDATA%\starlit-desktop`

里面有：

- 聊天记录与长期记忆
- 角色人格与头像
- 表情包
- 你的模型配置

星伴不会上传这些内容，也没有任何统计或埋点。唯一的外部请求是你自己配置的模型接口。

应用运行时会在数据目录放置锁文件，防止两个星伴同时改动同一份数据；如果看到「系统文件正在被占用」，说明还有另一个实例没有退出。

## 设计想法

星伴想做的不是「一个能聊天的模型」，而是一个**记得你、有自己的生活、会主动靠近**的伙伴。

所以很多设计都围绕「像人」而不是「像工具」：

- 回复会分成几条，中间有停顿
- 深夜不会突然发消息
- 你很久没回复，她会慢慢安静下来，而不是一直追问
- 记住的事会随聊天慢慢积累，而不是每次从头开始

当然，她仍然是一个本地程序。人设是设定，记忆是数据，情感体验由你自己定义。
